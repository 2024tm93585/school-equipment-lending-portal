## How to Use

### Step 1: Review the Documentation
```bash
cd school-equipment-lending-portal
open PROJECT_DOCUMENTATION.md  # macOS
# or
start PROJECT_DOCUMENTATION.md  # Windows
# or
xdg-open PROJECT_DOCUMENTATION.md  # Linux
```

### Step 2: Convert to Word
Follow instructions in `CONVERT_TO_WORD.md`

**Recommended Method**:
```bash
# Install Pandoc (if not already installed)
brew install pandoc  # macOS

# Convert to Word
pandoc PROJECT_DOCUMENTATION.md -o PROJECT_DOCUMENTATION.docx --toc
```

### Step 3: Final Formatting
1. Open PROJECT_DOCUMENTATION.docx in Microsoft Word
2. Update table of contents (References → Update Table)
3. Add page numbers (Insert → Page Number)
4. Add header with document title
5. Review and adjust formatting as needed
6. Save and submit
